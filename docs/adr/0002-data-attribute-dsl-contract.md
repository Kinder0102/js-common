# 0002 以 data-* 字符串作爲對外契約

## 狀態

已接受。

## 背景

綁定關係需要被「寫模板的人」配置，而寫模板的人通常不寫 JS。同時下游有三個包（`ajax-form` / `toggle` / `pagination`），各自需要擴展自己的鍵，但共用同一套解析與渲染。

## 決策

對外契約是 HTML 屬性上的字符串 DSL，不是 JS 配置對象。具體語法見 [js-dsl-factory](../api/js-dsl-factory.md#契約)。

```html
<div data-af-value="userName" data-af-value-type="text"></div>
```

- 屬性名 `data-{prefix}-{key}` 是唯一擴展點，新鍵不需要改本倉庫代碼。
- 值是一個用 `|` 與 `,` 分隔的輕量 DSL，不是 JSON。JSON 在 HTML 裏要轉義引號，不可讀。
- 每個值解析後統一是數組，消費方取 `[0]` 或整體遍歷。

## 理由

- 模板裏能直接看懂「這個元素綁了什麼」，不需要跳到 JS 裏找選擇器。
- 新增能力只增鍵，不改解析器，三個下游可以各自演進。
- 與服務端渲染、靜態模板天然兼容：頁面先出結構，JS 後綁定。

## 後果

- **屬性名即 API**。改鍵名等於破壞性變更，需要同步全部下游。
- 解析器必須自己處理轉義（`\,` `\|` `\:`），不能依賴 JSON。
- 鍵的語義不集中在類型裏，靠文檔與 `GLOSSARY.md` 維持一致性。
- 拼寫錯誤不會有編譯期報錯，只會靜默不生效。新增鍵後必須更新文檔。
